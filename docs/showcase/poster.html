The problem

Embedded devices need to retain settings and counters through restarts. An interrupted write can leave a partial record and uncertain state.

Our approach

Legder is a bounded key-value store. It writes one fixed-size record to a log and synchronizes it before changing the in-memory table.

Commit and recovery path

Put / Delete   →   Encode record   →   Write block   →   Sync   →   Update table

Restart   →   Check CRC and sequence   →   Replay valid consecutive prefix

What we implemented

  • 512-byte records with sequence number and CRC
  • Append-only write-ahead log and recovery scan
  • Bounded store with sorted-array binary-search lookup
  • RAM crash simulator and desktop file-backed device
  • Automated tests and Ubuntu GitHub Actions CI
